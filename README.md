## Ringkasan Project
Pemodelan data interaksi RetailRocket sebagai graf bipartit Visitor-Item menggunakan Neo4j dan driver Python. Graf dibangun berdasarkan data P1 (Training), kemudian digunakan untuk menghitung similarity item dan rekomendasi KNN yang dievaluasi pada P2 (Testing).
